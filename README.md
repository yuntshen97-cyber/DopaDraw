# DopaDraw
A random focus timer for people who overthink where to start.
> Stop deciding. Start doing.

DopaDraw is a lightweight random focus timer designed to help you overcome the hardest part of productivity:

**getting started.**

Instead of asking you to plan the perfect schedule,
DopaDraw randomly selects a task and a focus duration,
so you only have to make **one decision: press Start.**

---

## ✨ Features

- 🎲 Randomly draw your next task
- ⏱️ Random focus duration
- 📝 Add tasks anytime during a session
- 🔁 Requeue unfinished tasks
- ⏭️ Skip tasks
- 🌱 Optional 3-minute warm-up mode
- 🗓️ Completion calendar
- 💾 Local-first (no account required)
- 🔒 Privacy-first
- 🎁 Random completion rewards

---

## Philosophy

DopaDraw isn't about forcing productivity.

It's about reducing the tiny decisions that keep people from starting.

One less decision.

One step closer to beginning.

## 中文

### 功能

- 添加具体的小任务，并将清单保存在当前浏览器中。
- 随机抽取下一项任务和专注时长。
- 支持开始、暂停、继续、跳过、删除和完成任务，同时保留本轮其余内容。
- 难以启动时，可选择“三分钟启动”。
- 在完成日历中回看已经做完的事情。
- 可导出 JSON 备份，也可在之后重新导入。
- 中英文即时切换，并自动记住你的语言选择。
- 无需账号、无需安装，可在本地运行。

### 理念

DopaDraw 想减少的，是开始行动前的那一个决定。它不替任务排序，也不评价你的效率；它只抽出眼前的一步，给出一个时间边界，帮助你开始。

### 隐私

任务清单、完成历史、计时设置和语言偏好仅保存在当前浏览器的 localStorage 中。DopaDraw 不会把任务内容上传到服务器。清除浏览器数据可能导致记录丢失；重要数据请及时导出备份。

### 路线图

当前版本是本地优先的中英双语网页应用。未来可以考虑增加更多语言、可安装的 PWA 体验，以及由用户主动选择的跨设备同步。这些属于后续方向，不是当前版本已经提供的功能。

## Run locally / 本地运行

Open `dist/index.html` directly in a modern browser. If your browser restricts local files, serve the `dist` folder with any local static-file server and open its loopback URL.

使用现代浏览器直接打开 `dist/index.html`。如果浏览器限制本地文件访问，可用任意本地静态文件服务器托管 `dist` 文件夹，再打开对应的本机回环地址。
