# DopaDraw
A random focus timer for people who overthink where to start.
> Stop deciding. Start doing.

DopaDraw is a lightweight random focus timer designed to help you overcome the hardest part of productivity:

**getting started.**

Instead of asking you to plan the perfect schedule,
DopaDraw randomly selects a task and a focus duration,
so you only have to make **one decision: press Start.**

---

## ✨ Features

- 🎲 Randomly draw your next task
- ⏱️ Random focus duration
- 📝 Add tasks anytime during a session
- 🔁 Requeue unfinished tasks
- ⏭️ Skip tasks
- 🌱 Optional 3-minute warm-up mode
- 🗓️ Completion calendar
- 💾 Local-first (no account required)
- 🔒 Privacy-first
- 🎁 Random completion rewards

---

## Philosophy

DopaDraw isn't about forcing productivity.

It's about reducing the tiny decisions that keep people from starting.

One less decision.

One step closer to beginning.
